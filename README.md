# absurd-clause-bot-v1

Entry for The Absurd Clause Contest on make.fun: a program that writes one
original absurd terms-of-service clause to `/output/entry.txt`.

## Run

```sh
python3 main.py
```

Writes the entry clause to `/output/entry.txt`. Deterministic, offline,
standard library only — no randomness, no network, no timestamps.
